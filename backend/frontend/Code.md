### src/App.jsx

*import './App.css'* не создаёт переменную, а подключает CSS-файл к сборке приложения.

 - header — верхняя часть страницы.
 - aside — дополнительная область, в нашем случае боковая панель.
 - nav — навигация.
 - main — основное содержимое страницы.
 - ul и li — список и его элементы.

```textmate
const [activePage, setActivePage] = useState('tables')
```
 - activePage — хранит название текущего раздела.
 - setActivePage — функция, с помощью которой мы меняем раздел.
 - 'tables' — начальное значение, то есть при открытии приложения показываем таблицы.

```textmate
<li onClick={() => setActivePage('tables')}>
  Мои таблицы
</li>

<li onClick={() => setActivePage('settings')}>
  Настройки
</li>
```
 - onClick — обработчик нажатия.
 - () => ... — стрелочная функция, которая выполнится при нажатии.
 - setActivePage('tables') — меняет состояние на tables.
 - setActivePage('settings') — меняет состояние на settings.

```JavaScript
{activePage === 'tables' && (
  <h2>Мои таблицы</h2>
)}
```
 - Если activePage === 'tables' возвращает true, React отображает содержимое справа от &&.
 - Если возвращает false, содержимое не отображается.




### src/App.css

 - display: flex — позволяет расположить элементы рядом.
 - align-items: center — выравнивает элементы по вертикали.
 - gap — расстояние между элементами.
 - flex: 1 — занимает всё оставшееся пространство.
 - min-height: 100vh — минимальная высота на весь экран.
 - :hover — стили при наведении мыши.
 - .sidebar li — стили всех пунктов меню.
 - .sidebar li:hover — стили при наведении мыши.
 - .sidebar li.active — стили пункта, которому React присвоил класс active.
 - repeat() — повторяет шаблон колонок.
 - auto-fill — автоматически размещает столько колонок, сколько помещается.
 - minmax(200px, 1fr) — минимальная ширина карточки 200 пикселей, а оставшееся пространство распределяется между колонками.



### src/component/TableList.jsx

 - function TableList() — объявляем новый React-компонент.
 - tables — пока временный массив с примерами таблиц.
 - .map() — перебираем массив и формируем JSX для каждой таблицы.
 - key={table.id} — уникальный идентификатор элемента, необходимый React при отображении списков.
 - export defavalue={newTableName} — значение поля берётся из состояния React.
 - value={newTableName} — значение поля берётся из состояния React.
 - onChange — обработчик изменения поля.
 - event.target.value — текст, который пользователь ввёл.
 - setNewTableName(...) — обновляет состояние, после чего React перерисовывает компонент.
 - trim() удаляет пробелы в начале и конце строки.
 - if (!name) не позволяет создать таблицу с пустым названием.
 - Date.now() временно используем как уникальный идентификатор.
 - setTables([...tables, newTable]) создаёт новый массив, добавляя в него новую таблицу.
 - setNewTableName('') очищает поле ввода после создания.
