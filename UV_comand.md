## uv 
— это сверхбыстрый менеджер пакетов, проектов и виртуальных окружений Python от компании Astral, написанный на Rust и заменяющий инструменты вроде pip, poetry, venv и pyenv.

### Основные команды управления проектом

 - `uv init` — создать новый проект и файлы конфигурации (pyproject.toml).
 - `uv venv` — создать новое виртуальное окружение (.venv).
 - `uv add <pkg>` — добавить пакет в проект и зафиксировать его в зависимостях.
 - `uv remove <pkg>` — удалить пакет из проекта.
 - `uv sync` — синхронизировать зависимости проекта с файлом блокировки (uv.lock).
 - `uv lock` — обновить или сгенерировать файл uv.lock.

Запуск и выполнение кода`

 - `uv run <script.py>` — запустить Python-скрипт внутри изолированного окружения проекта.
 - `uv run <command>` — запустить любую консольную команду или инструмент (например, uv run pytest).
 - `uv tree` — вывести дерево зависимостей проекта.
 - `uvx <package>` — скачивает и запускает утилиту в один клик без установки в проект (например, uvx black .).


Работа с версиями Python

 - `uv python install <ver>` — скачать и установить указанную версию Python (например, uv python install 3.12).
 - `uv python pin <ver>` — зафиксировать версию Python для текущего проекта (создает .python-version).
 - `uv python list` — показать список доступных и установленных версий Python.

Утилиты и глобальные пакеты (uvx / uv tool)

 - `uvx <pkg> (или uv tool run <pkg>)` — запустить утилиту в изолированном временном окружении без установки (например, uvx ruff check .).
 - `uv tool install <pkg>` — установить консольную утилиту глобально.
 - `uv cache clean` — очистить кэш загруженных пакетов.
 - `uv self update` — обновить сам инструмент uv до последней версии.
